# Forst – Ice Cream Website 🍦

**Forst** is an ice cream website built to practice **JavaScript, HTML, and CSS**. It allows users to explore ice cream flavors and see dynamic UI updates, but **the order/cart functionality is not fully implemented**—this project is purely for learning and experimentation.

## 🌐 Live Demo

Check it out here: [https://forstdelight.netlify.app](https://forstdelight.netlify.app)

## 🚀 How to Use

1. Open the live demo: [https://forstdelight.netlify.app](https://forstdelight.netlify.app)
2. Browse ice cream flavors and explore the UI.
3. Click on a flavor to see **interactive effects**.
4. Note: **Adding to cart and order submission is not functional**—this project is for practice only.

## ⚙️ Running Locally

1. Clone the repository:

```bash
git clone https://github.com/Rosh-codes/Forst--Ice-Cream-Website.git
```

2. Navigate to the project folder:

```bash
cd Forst--Ice-Cream-Website
```

3. Open `index.html` in your browser.

## 🧠 Learning Goals

* Practice **JavaScript DOM manipulation**.
* Experiment with **CSS styling and layout**.
* Build **interactive elements** and learn event handling.
